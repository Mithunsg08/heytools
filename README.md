# HeyTools

45 free, private tools in one app. **No accounts, no ads. Your notes, photos and files stay on your device.**

- Website and installable web app: https://mithunsg08.github.io/heytools/
- Android app: download the latest APK from the [Releases](https://github.com/Mithunsg08/heytools/releases) page
- Privacy in plain words: https://mithunsg08.github.io/heytools/privacy/

## What makes it different

- **Private by design.** Data lives in on-device storage. There is no HeyTools server that receives it, no account and no ads. The [privacy page](https://mithunsg08.github.io/heytools/privacy/) lists every outside service a tool can contact.
- **Truly offline where it says so.** Fonts and libraries are shipped with the app (`fonts/`, `vendor/`). Tools labelled *Works offline* make no outside requests (checked by `scripts/validate-repo.js`).
- **Plays on in the background.** Music and video keep playing when you leave the tool, switch apps or lock the screen. A Pause/Play control stays in the app, and the Android notification has media controls.
- **Reliable reminders and alarms.** One master switch, switches for alarms, reminders, timers and update alerts, quiet hours, a test notification, and an "alarm reliability" check (notification permission, exact alarms, battery limits, a 1-minute test alarm). Alarms ring when the app is closed or the phone is locked, and show over the lock screen.
- **Real recording.** Voice with an animated orb, video in a full-screen camera like a phone camera app, and screen recording on desktop *and* on Android.
- **Long jobs keep going.** Compressing, converting and background removal carry on if you switch to another app (a quiet notification shows while they run).
- **Pinned tools, search, categories and recent tools** on the home screen.
- **Back up and restore** your data to a file (versioned, validated, never includes login tokens), and **Delete all my data** in one place.

## Project layout

| Path | What is in it |
| --- | --- |
| `app/` | The app shell: home screen, settings, onboarding, tool registry (`tools.js`), native bridge |
| `<tool>/index.html` | One self-contained page per tool |
| `heytools-sw.js` | Service worker: small shell first, then every tool, font and library in the background |
| `heynotify.js` | Notifications and alarms (Android native plugin, browser fallback) |
| `fonts/`, `vendor/` | Self-hosted fonts and libraries (versions and licences in `vendor/README.md`) |
| `privacy/` | The privacy page |
| `licenses/` | Open-source licenses page (generated by `scripts/build-notices.js`) |
| `native/` | Capacitor Android project scripts and Java plugins |
| `og/` | Share images (made by `scripts/make-og.py`) |
| `THIRD_PARTY_NOTICES.md`, `fonts/LICENSES.md` | License texts for bundled libraries and fonts |
| `scripts/` | Validation, SEO normalizer, notification tests, browser smoke test |

## Working on it

```bash
node scripts/validate-repo.js     # privacy, security, offline and SEO guards + syntax checks
node scripts/test-notifications.js
node scripts/seo-normalize.js     # canonical URLs, share tags, structured data, related links, sitemap
python3 scripts/make-og.py        # share images (needs Pillow)
node scripts/build-notices.js <dir with node_modules>   # license files (see vendor/README.md for the packages)
python3 -m http.server 8000       # then open http://localhost:8000/app/
```

**Add a tool:** create `<id>/index.html`, add a line to `app/tools.js`, add the id to `TOOLS` in `heytools-sw.js`, then run `seo-normalize.js`, `make-og.py` and `validate-repo.js`. Use `../fonts/fonts.css` for fonts and put any library in `vendor/` with an exact version. Never link Google Fonts or a CDN from a tool that is marked *Works offline*.

**Release:** bump `VERSION` in `heytools-sw.js` whenever the app shell or a tool changes. Android builds run from GitHub Actions. Keep the signing key safe (see [SECURITY.md](SECURITY.md)).

## Android app notes

The Android app is a [Capacitor](https://capacitorjs.com) shell built by GitHub Actions (`.github/workflows/android.yml`) and signed with a key kept in repository secrets (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`). Native code lives in `native/plugin/` and is copied in by `native/scripts/patch-android.js`.

| Native piece | What it does |
| --- | --- |
| `PlaybackService` | Foreground media service: notification controls, lock-screen session, wake lock, background audio |
| `HeyAlarmPlugin`, `AlarmScheduler`, `AlarmReceiver`, `AlarmRingingService` | Exact alarms that ring when the app is closed, over the lock screen, with snooze and stop |
| `ScreenRecordPlugin`, `ScreenRecordService` | Screen recording with MediaProjection (microphone optional), saved to Movies/HeyTools |
| `KeepAliveService` | Quiet foreground service while a long job runs |
| `MediaLibraryPlugin` | Paged scan of the phone's videos and music |
| `UpdateWorker` | Optional update check against the latest GitHub release |

Hardening: `allowBackup=false`, no cleartext traffic, private boot receiver, WebView debugging off. Permissions are listed on the privacy page. `USE_EXACT_ALARM` is deliberately not requested (Google Play policy); alarms use the user-granted *Alarms & reminders* permission, which onboarding asks for.

Test on a real phone before releasing: a locked-screen alarm, screen recording, music with the screen off, and a reminder after swiping the app away.
